# Implementation Approach

## Phases
| Phase | Activity | Owner |
|---|---|---|
| 1. Discovery | Understand PNB's collections process, volumes and agent workflow | Sales + Client |
| 2. Solution design | Design the call trigger, reminder, report and agent follow-up flow | Sales + Sarv team |
| 3. Message design | Define the reminder content: due amount and date | Client + Sales |
| 4. Portal integration | Connect the PNB portal to the Sarv platform for call requests and reports | PNB tech team + Sarv tech team |
| 5. Reporting setup | Generate the report in the Sarv portal and push it to the PNB portal | Sarv tech team + PNB tech team |
| 6. Testing | Test the reminder call, the not-picked-up report and the agent view | PNB + Sarv |
| 7. Go-live | Start automated reminders and agent follow-up | PNB |

## Responsibilities
**PNB:** portal, loan due data, live agents for manual follow-up.
**Sarv Group:** calling platform, automated calls, reports, report push to the PNB portal.
**Sales (me):** requirement discussions, solution proposal, coordination between teams.
